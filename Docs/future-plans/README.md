# Ghost Deploy Future Plans

This folder contains approved or proposed work that is deliberately outside the current MVA. These documents are not evidence that a feature is implemented, deployed, tested, or commercially available.

## Documents

1. `NON_MVA_ROADMAP.md` - consolidated post-MVA feature roadmap and delivery order.
2. `HOSTED_EMAIL_PLATFORM_PLAN.md` - native hosted-mail architecture using Stalwart, JMAP, and managed outbound relays.
3. `SERVER_CONSOLIDATION_PLAN.md` - migration from two hosting servers to one Coolify application server with a separate host-maintenance interface.

## Status rules

- Current MVA requirements and implementation evidence remain in the parent `Docs` folder.
- A future-plan item moves into active implementation only after scope, security, infrastructure, data migration, testing, and operational ownership are approved.
- Provider configuration text is not deployment evidence.
- Any completed future-plan feature must update `Docs/SRS_TRACEABILITY.md`, the API documentation, operational runbooks, and this index.
